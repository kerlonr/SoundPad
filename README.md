## Sobre

Mesa de sons feita para o evento **"Vai dar namoro"** dos terceirões: cada botão toca um efeito
sonoro ou meme, ideal para animar a apresentação ao vivo.

## Visão Geral

- um botão por som, tocando na hora
- **volume geral** ajustável
- botão **Parar todos** para cortar os sons de uma vez
- layout que se ajusta ao tamanho da tela

## Estrutura

```text
.
|-- index.html
|-- styles.css
|-- script.js     lista de sons, volume e controles
`-- sons/         arquivos .mp3
```

## Rodando Localmente

Projeto estático, sem dependências: basta abrir o `index.html` no navegador.
